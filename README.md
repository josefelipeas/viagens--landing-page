# Agência de viagens

Landing page simulando uma agência de viagens que programa viagens à cidade de Budapeste

## Descrição

Contém código HTML e CSS do devido projeto com 3 seções (Minha viagem, Conselhos e Nos encontre), banner mostrando imagem da capital com um texto de Overlay. Navegação entre as seções e âncora para o topo da página. E todos os âncoras mudam sua aparência original passando o mouse por cima do elemento.

## Execução

Projeto executado com o programa VSCODE utilizando a extensão Live Server.
